# 써는 놈 피하는 놈 — UI/UX Design Specification

## 1. 디자인 목표

동양 다크 판타지 분위기의 시네마틱 턴제 검술 게임을 구현한다.

게임은 단순한 검은색 졸라맨 캐릭터와 화려한 검격 이펙트, 깊이감 있는 배경을 결합한다.

전체적인 시각 디자인은 고급스러운 2D/2.5D 인디 액션 게임 스타일을 지향한다.

## 2. 전체 비주얼 스타일

- Dark Cinematic Fantasy
- Japanese-inspired Sword Duel
- Minimal Stickman Character
- Glowing Slash Effects
- Moonlit Battlefield
- Dark Blue and Black UI
- Red Attack / Blue Defense Highlights

배경에는 거대한 달, 산맥, 안개, 호수, 도리이, 벚꽃잎을 사용한다.

배경은 전투를 방해하지 않도록 어둡고 대비를 낮게 유지한다.

## 3. 화면 레이아웃

공격 턴과 방어 턴은 동일한 레이아웃을 공유한다.

- 왼쪽: 턴 이름, 설명, HP
- 중앙: 전투 및 조작 영역
- 오른쪽: 조작 방법, 게이지, 완료 버튼

중앙 전투 영역은 고정된 직사각형이다.

**공격과 방어의 전투 영역은 크기, 화면 위치, 화면 비율이 완전히 동일해야 한다.**

중앙 직사각형은 전투의 모든 입력을 제한하는 공통 좌표 공간으로 사용한다.

## 4. 캐릭터 디자인

캐릭터는 검은색의 단순한 졸라맨이다.

- 원형 머리
- 직선 또는 부드러운 선 형태의 몸통
- 양팔 및 양다리에 각각 하나의 관절
- 검은색 실루엣
- 밝고 얇은 외곽선
- 과도한 근육, 얼굴, 갑옷, 의상 사용 금지

방어 화면에서는 선택 가능한 관절마다 작은 파란색 원형 핸들을 표시한다.

관절을 움직일 때 연결된 신체 부위가 자연스럽게 움직이도록 한다.

## 5. 공격 턴 디자인

카메라는 1인칭이다.

플레이어가 쥔 검이 오른쪽 아래에 보이며, 상대 졸라맨은 중앙 직사각형 안에 표시된다.

마우스를 드래그하여 검격의 궤적을 그릴 수 있다.

검격은 밝은 흰색 중심선과 붉은색 발광 효과를 가진다.

마우스로 그릴 수 있는 위치는 중앙 직사각형 내부로 제한한다.

검격에는 최대 길이가 있으며, 오른쪽 게이지에 남은 길이를 표시한다.

완료 버튼을 누르면 검격이 확정되고 전투 애니메이션이 실행된다.

## 6. 방어 턴 디자인

카메라는 3인칭이며 플레이어 졸라맨의 전신이 보인다.

플레이어는 캐릭터의 머리, 몸통, 양팔, 양다리를 조작하여 자세를 변경할 수 있다.

각 관절은 파란색 원형 핸들로 표시한다.

마우스 드래그로 신체 부위를 조작한다.

모든 신체 부위는 중앙 직사각형 내부에 있어야 한다.

신체 부위끼리 겹치거나 관절 길이가 비정상적으로 늘어나는 동작은 허용하지 않는다.

완료 버튼을 누르면 최종 자세가 확정되고 상대 검격에 대한 피격 판정이 실행된다.

## 7. 컬러 시스템

- Background: #0D1323
- Panel: #283A57
- Attack Accent: #F0505B
- Defense Accent: #91B9FF
- Main Text: #F1EDF4

전체적인 색상은 채도를 낮게 유지하고 검격, 관절, 중요한 버튼에만 강한 빛을 사용한다.

## 8. UI 요소

- HP 바
- 턴 표시
- 검격 길이 게이지
- 마우스 조작 안내
- 완료 버튼
- 검격 입력 가능 영역 테두리
- 방어 조작 가능 영역 테두리

메뉴와 설명은 중앙 플레이 영역을 가리지 않도록 배치한다.

## 9. 애니메이션 및 카메라

공격 준비 단계에서는 1인칭 카메라를 사용한다.

방어 준비 단계에서는 3인칭 카메라를 사용한다.

턴 전환에는 짧고 부드러운 시네마틱 카메라 애니메이션을 적용한다.

검격 실행 시 붉은빛의 궤적과 잔상 효과를 적용한다.

피격 시 짧은 타격 정지, 화면 흔들림, HP 감소 애니메이션을 적용한다.

## 10. 디자인상 반드시 지킬 사항

1. 공격과 방어 영역의 크기 및 위치를 동일하게 유지한다.
2. 공격과 방어 입력은 반드시 해당 직사각형 내부에서만 가능하다.
3. 캐릭터는 단순한 졸라맨 디자인을 유지한다.
4. 복잡한 신체 이동 범위 표시나 각도 숫자를 화면에 추가하지 않는다.
5. 전투 조작 영역보다 배경 효과가 더 두드러지지 않도록 한다.
6. 공격은 붉은색, 방어는 푸른색으로 시각적으로 구분한다.
7. 실제 게임 화면은 콘셉트 이미지의 설명용 인포그래픽보다 간결하게 구성한다.

## 11. 변경 사항: 스테이지 선택과 보스 연출 (v2)

- 메인 메뉴의 난이도 버튼을 없애고 "게임 시작"을 누르면 스테이지 선택 화면으로 이동한다.
- 스테이지 선택 화면은 5×2 카드로 구성한다. 카드에는 단계 번호, 이름, HP, 해당 캐릭터의 작은 실루엣을 표시한다. 잠긴 카드는 어둡게 하고 자물쇠를 표시하며, 클리어한 카드에는 체크 표시를 한다. 보스 카드는 붉은 테두리로 구분한다.
- 전투 화면 상단에 스테이지 번호와 적 이름을 표시한다. 적 HP 바의 최대값은 스테이지 HP를 따른다.
- 승리 화면: "다음 단계", "다시 도전", "스테이지 선택". 패배 화면: "다시 도전", "스테이지 선택".
- 보스 등장 연출은 전투 영역과 장면에만 어두운 막을 씌우고, 상단·하단 UI 패널은 가리지 않는다.
- 방어 확정 후에는 웅크림, 점프, 자세 전환 애니메이션을 보여 준다.
